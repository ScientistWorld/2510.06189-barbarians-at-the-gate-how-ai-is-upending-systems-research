# Scientist Constraints

## Data

Use the deterministic traces generated by `data/generate_eplb_traces.py` and evaluated through `data/eplb_traces.json`. Do not add external traces or tune on a separate larger workload set, because the gym is meant to compare placement policies under fixed load changes.

## Problem Size

Keep the same logical expert count, replica count, group count, node count, and GPU count used in the generated traces. Changing these can alter the difficulty of both balance and operation-count metrics.

## Evaluation

Use `scripts/evaluate.sh` unchanged for final scoring. It must read placement artifacts from `outputs/eplb/` and write `scoring/scores.json`.

## Compliance Checklist

- [ ] Final scores use only the tracked deterministic EPLB traces
- [ ] Expert, replica, group, node, and GPU counts match the provided traces
- [ ] `scripts/evaluate.sh` is the scoring entry point
- [ ] No wall-clock runtime metric replaces `mean_operation_count`
